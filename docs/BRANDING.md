# Identidad visual de KeyMint

KeyMint utiliza una identidad tecnológica centrada en tonos mint, turquesa y azul navy.

El símbolo combina tres conceptos:

- La letra K.
- Una llave.
- Circuitos electrónicos.

La identidad representa seguridad, generación de contraseñas y tecnología.

---

## Recursos oficiales

| Archivo | Uso |
| --- | --- |
| `KeyMintLogo.png` | Logo principal de presentación con fondo propio de marca |
| `KeyMintLogoHorizontal.png` | Logo horizontal transparente para headers, GitHub y RobDev512 Hub |
| `KeyMintIcon.png` | Símbolo aislado transparente para aplicación, tarjetas y usos compactos |
| `KeyMintLogoTransparent.png` | Logo completo apilado y transparente |
| `KeyMintMono.png` | Versión monocromática para usos de un solo color |
| `KeyMintIcon.ico` | Icono multiresolución para Windows, ejecutable, instalador y accesos directos |

Los recursos oficiales se almacenan en:

assets/branding/

## Estándar de branding RobDev512

Los proyectos con identidad visual propia deberían disponer, cuando corresponda,
de los siguientes seis recursos:

1. `<Proyecto>Logo.png`
2. `<Proyecto>LogoHorizontal.png`
3. `<Proyecto>Icon.png`
4. `<Proyecto>LogoTransparent.png`
5. `<Proyecto>Mono.png`
6. `<Proyecto>Icon.ico`

### Logo

Identidad principal del proyecto.

Se utiliza en:

- portadas;
- documentación;
- páginas de presentación;
- material promocional.

### LogoHorizontal

Lockup horizontal con fondo transparente.

Se utiliza en:

- encabezados;
- RobDev512 Hub;
- GitHub;
- páginas web;
- banners compactos.

### Icon

Símbolo aislado y transparente.

Se utiliza en:

- aplicación;
- tarjetas del Hub;
- interfaces;
- espacios pequeños;
- generación de otros iconos.

### LogoTransparent

Versión completa de la identidad sin fondo.

Se utiliza cuando el fondo está controlado por la aplicación,
sitio web o documento.

### Mono

Versión monocromática.

Se utiliza en lugares donde la identidad cromática completa
no sea apropiada.

### Icon.ico

Versión multiresolución para Windows.

Debe incluir, cuando sea posible:

- 256x256
- 128x128
- 64x64
- 48x48
- 32x32
- 16x16

Se utiliza en:

- ejecutables;
- instaladores;
- accesos directos;
- ventanas de Windows.

## Recursos web derivados

Los recursos web pequeños no necesitan diseñarse como logos independientes.

Deben derivarse del archivo `<Proyecto>Icon.png`.

Entre ellos:

- favicon.ico
- favicon-16x16.png
- favicon-32x32.png
- favicon-64x64.png
- icon-192.png
- icon-512.png
- apple-touch-icon.png

De esta forma se conserva exactamente la misma identidad visual en aplicación,
GitHub, páginas web y RobDev512 Hub.
